# Storybook Usage Guide

Storybook is used in this project to develop, document, and visually test React components in isolation. This guide explains how to view, create, and document components using Storybook.

## Viewing Documentation

### Online

A GitHub Action automatically builds and deploys the latest Storybook documentation to GitHub Pages after each merge to `main`:

- [View Storybook documentation](https://onsdigital.github.io/blaise-design-system-react-components)

### Locally

To run Storybook locally:

```shell
yarn storybook
```

This will start Storybook at [http://localhost:6006](http://localhost:6006), where you can browse and interact with all documented components.

## Creating Component Stories

To document a component, create a `.stories.tsx` file next to the component file. For example, for `Button.tsx`, create `Button.stories.tsx` in the same folder.

### Basic Story Structure

```tsx
import type { Meta, StoryObj } from "@storybook/react-vite";
import { Button } from "./Button";

const meta = {
  title: "Components/Button", // Controls sidebar grouping
  component: Button,
  argTypes: {
    onClick: { action: "clicked" }, // Example: add actions for events
  },
} satisfies Meta<typeof Button>;

export default meta;

type Story = StoryObj<typeof meta>;

export const Primary: Story = {
  args: {
    primary: true,
    label: "Primary Button",
  },
};
```

- **`title`**: Controls where the story appears in the sidebar. Use slashes for subfolders (e.g., `Components/Error Boundary/Panel`).
- **`component`**: The React component being documented.
- **`argTypes`**: (Optional) Configure controls and actions for props/events.
- **`args`**: Default props for each story variant.

### Creating Variants

You can define multiple variants by exporting additional stories:

```tsx
export const Secondary: Story = {
  args: {
    primary: false,
    label: "Secondary Button",
  },
};

export const Loading: Story = {
  args: {
    ...Primary.args,
    loading: true,
    label: "Loading Button",
  },
};
```

## Adding Additional Information

Storybook automatically pulls TSDoc comments from your components and props into the Docs tab. For richer documentation:

- Add JSDoc comments above your component and its props:

```tsx
/**
 * A button component for user actions.
 */
export function Button(props: ButtonProps) { ... }

export interface ButtonProps {
  /**
   * The label to display inside the button.
   */
  label: string;
  /**
   * Whether the button is styled as primary.
   */
  primary?: boolean;
  // ...other props
}
```

- You can also use the `parameters.docs.description` field in your story meta for extra context.
